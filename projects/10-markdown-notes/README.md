# Project 10 — Markdown Notes Application

Note-taking app with Markdown preview and local storage.

## Features

- Create, edit, delete notes
- Markdown editing and preview
- Search functionality
- Tags
- Local persistence (localStorage)
- Import/export
- Keyboard shortcuts

## Technology Stack

- Pure JavaScript (ES2022+)
- localStorage
- Simple Markdown parser (safe)

## Installation

Open `src/index.html` in a browser.

## Usage

1. Click "New Note" to create
2. Edit in left pane, preview in right
3. Add tags (comma-separated)
4. Search notes by title/content
5. Export/import JSON

### Keyboard Shortcuts

- `Ctrl+N` - New note
- `Ctrl+S` - Save (auto-saves on edit)
- `Ctrl+F` - Focus search

## Known Limitations

- Basic Markdown support
- No collaborative editing
- No cloud sync
- No file attachments
